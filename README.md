# Predictive Maintenance for Industrial Machines

## Project Overview
This project uses Machine Learning to predict the risk of industrial machine failure based on operating conditions.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Flask
- HTML and CSS

## Features
- Machine failure prediction
- Random Forest classification model
- Model performance evaluation
- Interactive dashboard
- Failure risk warning

## Dataset
AI4I 2020 Predictive Maintenance Dataset.

## How to Run
1. Install the required Python libraries.
2. Make sure the dataset and trained model files are available.
3. Run `python app.py`.
4. Open the local URL displayed in the terminal.

## Purpose
Developed as an academic Advanced Data Science project.
